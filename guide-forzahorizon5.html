Tuning & Upgrades Guide

Basic Tuning Principles

Tire Pressure

Lower for grip (28-30psi), higher for speed (32-35psi). Adjust for weather.

Gearing

Final drive: lower for acceleration, higher for top speed. Adjust per track.

Alignment

Camber: -1.5 to -2.5 for cornering. Toe: 0.2 in for stability.

ARB & Springs

Stiffer front reduces understeer. Stiffer rear reduces oversteer.

Drivetrain Conversions

RWD (Rear-Wheel)

Best for drifting and road racing. Requires throttle control.

Drift Road

AWD (All-Wheel)

Best for launches and dirt. Meta for most races.

All-terrain Meta

FWD (Front-Wheel)

Understeer prone. Only for specific B-class builds.

Upgrade Paths by Class

A Class Build

Engine + intake + exhaust. Sport tires. Race suspension. AWD swap if needed.

S1 Class Build

Race engine parts. Race tires. Weight reduction. Full aero.

S2/X Class Build

Dirt/Rally Build

Rally tires. Rally suspension. AWD. Dirt gearbox.

Advanced Tips & Tricks

Racing Techniques

Racing Line

Brake before corners, apex late, accelerate out. Use full track width.

Braking Points

Look for track markers. Brake in straight line, trail brake into corners.

Manual + Clutch

Faster shifts. Learn for competitive advantage. Practice in rivals.

TCS/STM Off

Faster with practice. Use for better acceleration out of corners.
